# Pocket Budget — учебный iOS-проект

Учёт доходов и расходов с четырьмя вкладками.

## В этой версии
- Выбранная валюта применяется к отображению сумм во всех вкладках. Важно: переключение валюты меняет формат отображения, но пока не конвертирует числовые суммы по курсу.
- Нажатие на операцию открывает подробную карточку.
- Удаление доступно через долгое нажатие на строку или из подробностей. Удаление выполняется в SwiftData, поэтому запись исключается и из списка, и из расчётов статистики/баланса.
- Будущие операции учитываются отдельно: «Текущий баланс» включает операции на сегодня и раньше, «Ожидаемый баланс» добавляет к нему будущие доходы и вычитает будущие расходы.
- В статистике фактические операции и будущие планы разделены.
- В настройках можно ввести имя пользователя.

## Где хранятся данные
Операции хранятся локально в базе SwiftData внутри контейнера приложения на устройстве/симуляторе. Имя, валюта и переключатели настроек хранятся локально через `AppStorage` (UserDefaults). Данные не отправляются на собственный сервер и не синхронизируются между устройствами. Удаление приложения обычно удаляет и локальные данные.


Сеть используется только для получения курсов валют из `open.er-api.com`; без интернета учёт операций продолжает работать.

## Архитектура
- `Models/Transaction.swift` — модель SwiftData.
- `Data/TransactionRepository.swift` — протокол и реализация локального хранилища.
- `Data/ExchangeRateService.swift` — сетевой сервис и протокол.
- `ViewModels/` — состояние и бизнес-логика.
- `Views/` — интерфейс; список транзакций реализован на UIKit `UICollectionView`, остальные экраны на SwiftUI.
